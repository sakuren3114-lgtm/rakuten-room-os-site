# 楽天ROOM OS

楽天市場の商品情報を活用し、楽天ROOMで紹介する商品の探索・分析・選定を支援する個人用システムです。

## 利用目的

楽天市場APIから商品情報を取得し、商品候補の探索、情報整理、商品選定、投稿内容の作成を支援します。

## APIの利用

楽天ウェブサービスのAPIを利用しています。

取得した商品情報は、楽天ROOM運用における商品選定・分析・投稿準備の目的で利用します。

## 運用方法

本システムは商品選定や投稿準備を自動化しますが、楽天ROOMへの投稿操作は利用者が確認したうえで手動で行います。
